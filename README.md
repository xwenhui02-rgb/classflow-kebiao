# ClassFlow · 课时 — 个人专属智能课程表

> 以「现在」为核心的个人学习时间中枢 · Apple-inspired
> 数据来源：广东轻工职业技术大学 教务系统个人课表（制药243 · 徐文辉 · 2026-2027-1）

## 快速开始

**方式一（推荐）：** 直接双击 `index.html` 用浏览器打开即可使用。

**方式二（完整体验，含 PWA 离线 + 安装到主屏）：**

```bash
cd 网页课程表
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

iOS Safari → 分享 → 添加到主屏幕，即可像原生 App 一样全屏使用。

## 六大模块

| 模块 | 说明 |
|------|------|
| **现在 NOW** | 打开即见：正在上课 / 下一节课 / 今日结束 / 假期中，实时倒计时 + 课堂进度条 + 建议出发时间 |
| **今天 TODAY** | 纵向时间轴，NOW 指示线随时间移动，过去课程自动降权，午休/晚餐自动识别 |
| **周表 WEEK** | 传统周课表 + 大留白圆角课程块，跨节连堂自动合并，实训课斜纹标识，支持翻周 |
| **日历 CALENDAR** | 月历视图，课程色点表示当天密度，点击查看当日安排 |
| **考试 EXAM** | 考试倒计时、考核方式汇总（考试/考查）、期末周预估，可手动添加考试 |
| **设置** | 主题、时间旅行、学期起始日、提前量、导出、快捷键 |

## 相比原需求文档新增 / 完善

1. **时间旅行（预览模式）** — 学期未开始或想提前查看某天课表时，可把「当前时间」拨到任意日期+时刻，完整体验上课中/课间/课后的所有状态。顶栏日期胶囊即入口。
2. **整周实训与整周实践** — 第 1 周社会实践（二）、第 10/11/12 周药品生产综合实训（三位不同教师轮值）作为「全天事件」正确呈现，不占用节次格。
3. **国定假日自动停课** — 中秋、国庆、元旦自动停课，可一键关闭；月历与周表均标注。
4. **调课标记** — 任意一节课可标记为「本次调课/停课」，进度、周表、ICS 导出同步排除，可撤销。
5. **课程进度可视化** — 每门课显示「已上 X / 共 Y 次」，用色块时间线表达每一次课（深色=已上、描边=这一次）。
6. **教室智能解析** — `4201` → 第 4 教学楼 2 层；`第三工业实训楼C206` → 北区实训区 2 层，详情页直接告诉你楼宇与楼层。
7. **冲突检测** — 同一时段出现两条课时时首页给出提示。
8. **日历导出 (.ics)** — 一键导出全学期 100+ 节课（含考试与整周实训），每节课自带上课前提醒；单节课也可单独导出。
9. **课程笔记** — 每门课可写备注（作业、要带的器材），存本机 localStorage。
10. **无障碍与动效克制** — 全键盘可操作（1–5 切视图、←→ 换天、T 回今天、/ 设置）、44px 热区、`prefers-reduced-motion` 完整支持、等宽数字避免倒计时抖动。

## 数据约定

- 学期第 1 周周一默认 **2026-09-07**（可在「设置 → 第 1 周起始日」修改）。
- 课表原始数据在 `assets/js/data.js`，纯数据无逻辑，改课表只需动这一个文件。
- 个人数据（考试、笔记、调课、设置）存浏览器 localStorage，可在设置里备份/恢复 JSON。

## 技术栈

纯 HTML + CSS + 原生 JavaScript，零依赖、零构建，可直接静态部署（GitHub Pages / Vercel / Cloudflare Pages）。
Service Worker 提供离线缓存，Web App Manifest 支持安装到主屏。

## 目录结构

```
index.html              应用外壳 + SVG 图标精灵
manifest.webmanifest    PWA 配置
sw.js                   离线缓存
icons/                  应用图标（SVG + PNG 192/512/180）
assets/css/
  tokens.css            设计令牌：色板、圆角、间距、字体、明暗主题
  base.css              重置、排版、应用骨架、导航
  components.css        卡片/按钮/标签/进度/弹层/表单
  views.css             六个视图的专属样式
assets/js/
  data.js               课表原始数据（课程、排课、整周、假日、教室）
  time.js               日期与教学周工具、周次表达式解析
  engine.js             状态机、进度、冲突检测、考试、存储
  render.js             视图 HTML 生成
  app.js                路由、主题、事件、导出、PWA
```
